# Saved media library

Drop files in these folders to make them show up as one-click options in the app
(no re-uploading needed — they're cloned with the notebook every run).

## `bgm/`  → background music
Put `.mp3`, `.wav`, `.ogg`, `.m4a`, `.flac` or `.aac` files here.
They appear in the **"💾 Saved BGM"** dropdown in the Crop/Filter section.

## `lut/`  → color LUTs
Put `.cube`, `.3dl`, `.csp`, `.m3d` or `.mga` files here.
They appear in the **"💾 Saved LUT"** dropdown.

Notes:
- Keep each file under GitHub's 100 MB limit.
- Pick the saved option **or** upload a new one each run — the saved option just saves you the upload.
